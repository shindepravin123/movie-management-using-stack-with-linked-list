# Movie Management Using Stack and Linked List

## Description
This project is a simple Movie Management System implemented in C++.

It uses:
- Linked List
- Stack
- LIFO (Last In First Out)

## Operations
1. Add Movie
2. Remove Movie
3. Display Movies
4. Exit

## Data Structure
The linked list stores movie details such as movie name and release year.

The stack is implemented using a linked list.

## Language
C++

## Concept
- Push: Add a movie to the stack.
- Pop: Remove the recently added movie.
- Display: Show all movies in the stack.

## How to Run

Compile the program:

g++ movie_management.cpp -o movie

Run:

./movie
